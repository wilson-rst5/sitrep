# Contributing

Open an issue with the use case and verification steps. Keep changes focused and include contract tests for new provider adapters. Review [development](docs/development.md), [testing](docs/testing.md) and [provider development](docs/provider-development.md).

Keep credentials, private monitoring preferences, database exports and deployment logs out of commits and example content. Use sanitised fixtures and cite the provider’s documentation and usage terms.

Contributions to SITREP are made under Apache 2.0.
